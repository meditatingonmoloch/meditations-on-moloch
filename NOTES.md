# Notes on “Moloch” as a Systems Pattern

## Short definition

“Moloch” is a poetic name for destructive optimization pressure: the force created when many agents must compete under rules that reward behavior nobody would choose in a cooperative setting.

## Minimal model

```text
Actors + competition + inability to coordinate + survival pressure = Moloch-like dynamics
```

## Practical diagnostic

A situation may be Moloch-like if people say things like:

- “I hate doing this, but if I stop, someone else will beat me.”
- “Everyone knows this is bad, but nobody can afford to be first to change.”
- “The system rewards exactly the behavior we complain about.”
- “Any actor with more restraint gets selected out.”

## Possible interventions

- Change incentives.
- Add enforceable agreements.
- Create trusted coordination channels.
- Increase transparency.
- Reduce winner-take-all dynamics.
- Protect slack.
- Build institutions with explicit values and accountability.
